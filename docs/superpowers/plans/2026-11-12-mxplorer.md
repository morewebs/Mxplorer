# Mxplorer Implementation Plan

**Goal:** Deliver a usable native Windows browser and installer with modern monochrome chrome.
**Architecture:** React controls own persistent UI state. Rust creates isolated native child webviews and emits tab/navigation/download events to the trusted main view.
**Tech Stack:** Tauri 2, WebView2, Rust, React, TypeScript, Vite, Vitest, Playwright.
**Spec:** ../specs/2026-11-12-mxplorer-design.md

## Global constraints
- Product name Mxplorer; Windows first; modern monochrome dark UI.
- Native webviews, no iframe browsing; no remote native privileges.
- Keep all work in the new Projects/Mxplorer repository.

## Review focus
- Redirects and in-page navigation must update the omnibox and native back/forward state.
- Fast tab changes and closing during loading must leave the correct view visible.
- Panels must not be covered by native webviews.
- Remote sites must not invoke privileged commands or load trusted local content.
- Restored sessions, malformed persisted values, and duplicate filenames must be safe.

## Native contract
Commands (camelCase JS args): create_tab {id,url,bounds}; activate_tab {id: string|null,bounds}; close_tab {id}; navigate_tab {id,url}; tab_action {id,action,value?}; resize_content {bounds}; window_action {action}; open_downloads; clear_browsing_data.
Bounds: {x,y,width,height} in logical CSS pixels. IDs match tab-[a-zA-Z0-9-]+.
Events to main: tab-update {id,url?,title?,loading?,canGoBack?,canGoForward?}; new-tab {url}; browser-shortcut {action}; download-update {id,url,name,path,status}. Status downloading/completed/failed.
Actions: back, forward, reload, stop, zoom, find, print. Shortcut actions: new-tab, close-tab, focus-address, reload, hard-reload, history, downloads, bookmarks, bookmark-page, find, next-tab, previous-tab, restore-tab, zoom-in, zoom-out, zoom-reset, fullscreen.
